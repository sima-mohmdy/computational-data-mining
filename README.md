
# Computational Data Mining

This repository contains my implementations and practical work for the **Computational Data Mining** course.

The assignments focus on understanding how different types of data—such as images, text, graphs, and tensors—can be represented mathematically and analyzed using computational data mining techniques.

---

## 🧭 Learning Path

The assignments follow a progression from basic data representation to more advanced data mining techniques:

```text
Image & Data Representation
          ↓
Matrix Decomposition
          ↓
QR Decomposition
          ↓
SVD & Low-Rank Approximation
          ↓
NMF & K-Means Clustering
          ↓
Graph Analysis & PageRank
          ↓
Tensor Decomposition & HOSVD
          ↓
Text Mining & Information Extraction
          ↓
Manifold Learning & Dimensionality Reduction
```

```text
  ↓
Algorithm
  ↓
Analysis
  ↓

```

Through these assignments, I practiced applying computational data mining methods to different forms of data and developed a stronger understanding of the mathematical and computational ideas behind them.
